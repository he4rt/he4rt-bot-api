# Plano de Implementação — MVP de live streaming local

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Transmitir do OBS via RTMP para um mediamtx local (Docker) e assistir via HLS na página `/live` do portal, com stream key validada pelo Laravel.

**Architecture:** mediamtx como serviço no docker-compose (ingest RTMP 1935, HLS 8888, Control API 9997) delegando autenticação de publish a um endpoint HTTP do novo módulo de domínio `app-modules/live/`; o portal (presentation) exibe a página `/live` com player hls.js e polling de status.

**Tech Stack:** Laravel 12/PHP 8.5, internachi/modular, Livewire 3, Pest 5, Tailwind 4, Vite (rolldown), hls.js, mediamtx v1.20.1.

**Spec:** `docs/specs/2026-08-29-live-mvp-design.md` (autoridade em conflitos) e pesquisa em `docs/specs/2026-08-29-live-streaming-viabilidade.md`.

## Global Constraints

- **Comentários em código são proibidos.** Única exceção: docstring de UMA linha em função/classe/tipo.
- Todo PHP: `declare(strict_types=1);`, classes `final`, tipos explícitos em parâmetros e retorno.
- DTOs são `final readonly class` — nunca array associativo cruzando fronteira.
- Actions (classe de ação única), nunca `*Service`; sem Repository; interfaces seriam `*Contract` (não há neste MVP).
- Dependência intra-repo em composer.json SEMPRE `"he4rt/x": "^1.0.0"` (caret, três dígitos).
- Sem migrations neste MVP — nada de banco.
- Strings de UI em pt_BR.
- Commits: conventional commits `<type>(<escopo>): ...` em pt_BR. **NUNCA** adicionar `Co-Authored-By` nem citar Claude.
- Após editar qualquer PHP: `vendor/bin/pint --dirty --format agent`.
- Testes: rodar SOMENTE o subconjunto do que mudou, ex. `./vendor/bin/pest app-modules/live/tests` — **sem `--parallel`**. Nunca rodar `pest --parallel` sem `--processes=10`.
- PHPStan por tarefa: `vendor/bin/phpstan analyse app-modules/<modulo>/src --ansi`.
- O hook lint-staged roda prettier em js/yml/md no commit — reformatações automáticas são esperadas; NÃO editar config do husky.
- O commit do lint-staged exige `npx`; se um commit falhar por causa do hook, reportar em vez de usar `--no-verify`.
- Rotas de módulo são auto-descobertas em `app-modules/<mod>/routes/*.php` pelo internachi/modular.
- Implementadores NÃO despacham subagentes.

- [ ] **Step 4: Implementar DTO, Action, Controller e rota**

`src/DTOs/IngestAuthPayload.php`:

```php
<?php

declare(strict_types=1);

namespace He4rt\Live\DTOs;

/** Payload que o mediamtx envia ao hook de autenticação HTTP externa. */
final readonly class IngestAuthPayload
{
    public function __construct(
        public string $action,
        public string $path,
        public string $user,
        public string $password,
        public string $ip,
        public string $protocol,
        public string $query,
    ) {}

    /** @param array<string, mixed> $payload */
    public static function fromArray(array $payload): self
    {
        $string = static fn (string $key): string => is_string($payload[$key] ?? null) ? $payload[$key] : '';

        return new self(
            action: $string('action'),
            path: $string('path'),
            user: $string('user'),
            password: $string('password'),
            ip: $string('ip'),
            protocol: $string('protocol'),
            query: $string('query'),
        );
    }
}
```

`src/Actions/AuthorizeMediaServerAction.php`:

```php
<?php

declare(strict_types=1);

namespace He4rt\Live\Actions;

use He4rt\Live\DTOs\IngestAuthPayload;

/** Decide se o mediamtx pode executar a ação solicitada: leitura é pública, publish exige a stream key. */
final readonly class AuthorizeMediaServerAction
{
    public function execute(IngestAuthPayload $payload): bool
    {
        if ($payload->action !== 'publish') {
            return true;
        }

        $streamKey = config()->string('live.stream_key');

        if ($streamKey === '') {
            return false;
        }

        return hash_equals($streamKey, $payload->password);
    }
}
```

`src/IngestAuthController.php`:

```php
<?php

declare(strict_types=1);

namespace He4rt\Live;

use He4rt\Live\Actions\AuthorizeMediaServerAction;
use He4rt\Live\DTOs\IngestAuthPayload;
use Illuminate\Http\Request;
use Illuminate\Http\Response;

final class IngestAuthController
{
    public function __invoke(Request $request, AuthorizeMediaServerAction $action): Response
    {
        $payload = IngestAuthPayload::fromArray($request->json()->all());

        abort_unless($action->execute($payload), Response::HTTP_FORBIDDEN);

        return response()->noContent();
    }
}
```

- [ ] **Step 7: Implementar `LiveStatus` e `CheckLiveStatusAction`**

`src/DTOs/LiveStatus.php`:

```php
<?php

declare(strict_types=1);

namespace He4rt\Live\DTOs;

use Carbon\CarbonImmutable;

/** Estado atual da transmissão segundo a Control API do mediamtx. */
final readonly class LiveStatus
{
    public function __construct(
        public bool $onAir,
        public ?CarbonImmutable $startedAt,
    ) {}

    public static function offline(): self
    {
        return new self(onAir: false, startedAt: null);
    }
}
```

`src/Actions/CheckLiveStatusAction.php`:

```php
<?php

declare(strict_types=1);

namespace He4rt\Live\Actions;

use Carbon\CarbonImmutable;
use He4rt\Live\DTOs\LiveStatus;
use Illuminate\Http\Client\ConnectionException;
use Illuminate\Support\Facades\Http;

/** Consulta a Control API do mediamtx para saber se a live está no ar. */
final readonly class CheckLiveStatusAction
{
    public function execute(): LiveStatus
    {
        try {
            $response = Http::timeout(2)->get(sprintf(
                '%s/v3/paths/get/%s',
                config()->string('live.control_api_url'),
                config()->string('live.path'),
            ));
        } catch (ConnectionException) {
            return LiveStatus::offline();
        }

        if (! $response->ok() || $response->json('ready') !== true) {
            return LiveStatus::offline();
        }

        $readyTime = $response->json('readyTime');

        return new LiveStatus(
            onAir: true,
            startedAt: is_string($readyTime) ? CarbonImmutable::parse($readyTime) : null,
        );
    }
}
```

```js
import Hls from 'hls.js';

const mount = () => {
    const video = document.querySelector('video[data-live-player]');
    if (!video || video.dataset.mounted === 'true') return;
    video.dataset.mounted = 'true';
    const src = video.dataset.hlsUrl;
    if (video.canPlayType('application/vnd.apple.mpegurl')) {
        video.src = src;
        return;
    }
    if (Hls.isSupported()) {
        const hls = new Hls();
        hls.loadSource(src);
        hls.attachMedia(video);
    }
};

document.addEventListener('DOMContentLoaded', mount);
document.addEventListener('livewire:init', () => {
    Livewire.hook('morphed', mount);
});
```
